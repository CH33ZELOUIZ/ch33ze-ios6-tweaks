Install

  1. In Cydia on iOS 6, add http://cydia.personaltechwiz.com/ as a source. Use HTTP, not HTTPS.
  2. Install NavTunes.
  3. Open Music → Navidrome → Settings and enter your server, username, and password or token/salt.
